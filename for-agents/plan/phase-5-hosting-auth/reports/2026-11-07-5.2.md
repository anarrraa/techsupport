## Changed
- `src/backend/auth.ts` (new, framework-free) — `authConfig` (all six vars or none; partial, short `SESSION_SECRET`, non-https `PUBLIC_URL` throw naming the variable), `assertExposure` (no auth + non-loopback host → throw), HMAC-SHA256 `signCookie`/`verifyCookie` (expiry inside the signed payload, `timingSafeEqual`), `startLogin` (state, nonce, S256 challenge; verifier carried in a signed 10-min `login` cookie), `finishLogin` (state check, token endpoint with a 10 s `AbortSignal.timeout`, `jwtVerify` against the tenant v2.0 JWKS with iss/aud/exp, nonce, `groups` must contain the allowed id; missing `groups` = 403, no Graph call), `readSession`, `logoutUrl`.
- `src/backend/server.ts` — `createApp(…, auth, loginDeps)`: `/health` and new `/api/health` open; with auth: `/api/auth/login|callback|logout` open, then a guard on `/api` (401 `Sign in required`), `/api/auth/me` → `{name}`. Startup reads `PORT ?? BACKEND_PORT`, runs `authConfig` + `assertExposure` before listening. Removed the unused `export const app`.
- `package.json` / `package-lock.json` — `jose` 6.2.3 promoted from transitive (already in the tree via `@google/genai`) to a direct dependency, same version; lockfile regenerated with `node:22.19.0` (npm 10), one-line diff. No new package.
- `tests/backend/auth.test.ts` (new, 11 tests) — RS256 key generated locally, tokens signed with `jose` `SignJWT`, fake token endpoint: config/partial config, loopback rule, real process exits non-zero on `0.0.0.0` without auth env, tampered/forged/wrong-key/expired cookie, PKCE + cookie flags, member gets 8 h session, wrong group/overage → 403, bad nonce/issuer/audience/expired token → 401, bad state → 400, HTTP: no/tampered/expired cookie → 401 on `/api/*`, health open, callback 403 sets no cookie, login/callback/logout redirects, no-auth mode unchanged.
- `AGENTS.md` — `jose` only in `src/backend/auth.ts`. `for-agents/env.md`, `.env.example` — the six auth vars, `PORT`.
