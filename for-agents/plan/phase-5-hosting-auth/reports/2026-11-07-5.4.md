## Asked
Roadmap 5.4: multi-stage Dockerfile (node from `.node-version`, `npm ci` with committed lockfiles, frontend build, prisma generate, non-root, `PORT`, `BACKEND_HOST=0.0.0.0`), `.dockerignore`, Express serves `frontend/dist`, docker proof, README runbook with placeholders. Run no gcloud/deploy command.

## Changed
- `Dockerfile` — build stage: root `npm ci` (postinstall = `prisma generate`), frontend `npm ci` + `npm run build`; runtime stage: `npm ci --omit=dev --ignore-scripts`, copies `src` (with the generated client), `assets` (PDF fonts), `frontend/dist`; `USER node`; `NODE_ENV=production BACKEND_HOST=0.0.0.0 PORT=8080`; `CMD node src/backend/server.ts` (Node 22.18+ strips types, as the tests already rely on). `ARG NODE_VERSION` defaults to 22.19.0; the runbook passes `$(cat .node-version)`.
- `.dockerignore` — `.env`, `.env.*`, `gcp-sa.json`, `documents/`, `config/*.json` (+ nested), `.escalation-state/`, `node_modules/` (both), `dist/`, `frontend/dist/`, generated Prisma client, `.git/`.
- `src/backend/server.ts` — when `frontend/dist` exists (param, default path), `express.static` + SPA fallback to `index.html` for every non-`/api/` GET; no session needed for static files.
- `tests/backend/auth.test.ts` — 1 test: static + SPA fallback served, `/api/unknown` still 401.
- `README.md` — "Deploy (Cloud Run)" runbook (services, Cloud SQL + `db:push` via Auth Proxy, secrets, service account roles, Artifact Registry, `gcloud run deploy` with env + secrets, Entra app registration steps, curl checks), all ids as `<PLACEHOLDER>`; backend section notes the fail-closed rule.

## Verified

- `docker build --build-arg NODE_VERSION=$(cat .node-version)` → success, 215 MB. Inside: user `node`; no `/app/config`, `/app/documents`, `.env*`, or `gcp-sa.json`.

  - log `Backend listening on http://0.0.0.0:8080 (Entra login)`

  - `/dashboard` 200 (SPA), `/api/auth/login` 302 to `login.microsoftonline.com/<fake tenant>/oauth2/v2.0/authorize`
  - with a session cookie signed by the same secret: `/api/auth/me` 200; `/api/reports/2026-10` passed auth and returned 503 (schema not pushed to the throwaway DB — expected)
