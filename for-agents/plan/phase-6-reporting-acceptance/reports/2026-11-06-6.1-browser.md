Other checks:
- Mobile nav drawer (only custom overlay), re-tested at 390x844 after the review fixes: every close path returns focus to the menu button: X by keyboard, X by mouse, backdrop click, Escape, and a NavLink (Enter on "Reports" navigated, focus on the menu button, the next Tab reaches the language button). Opening with a mouse click also restores focus to the menu button, because the opener is stored from the click target rather than `document.activeElement`.
- Widening to 1440 while the drawer is open closes it (overlay removed; back at 390 the drawer stays closed). The menu button is `display:none` at lg, so focus falls to `<body>` in that one case.
- Headless note: CSS transitions and `matchMedia` change events only advance when a frame is produced (a screenshot). Mouse clicks on the sliding drawer and the resize check needed a screenshot first; keyboard paths did not.
- Month pickers and selects are native controls.
- No keyboard trap on any page; Tab cycles back to the first control.
- Focus ring visible on every stop (ring or outline), including month-input segments.
- Month input: ArrowUp/Down changes the month and updates `?month=`.
- Support upload: file picked → period auto-filled → group button (Enter) → `POST /api/support-reports` 200. Missing-column file → visible alert.
- Dashboard PDF export button → `GET …/export?format=pdf` 200, no alert.
- Chart: bars render once the entry animation ends; Recharts' SVG is one keyboard stop with a ring (library default, arrow keys move the tooltip).

## Changed
- `frontend/src/shared/components/layout/Sidebar.tsx` — **fix A**: the closed mobile drawer was translated off-screen but its 5 controls stayed in the Tab order (invisible focus). Closed drawer is now `invisible` below `lg`; opening moves focus to the close button. After review: focus is restored in the effect cleanup, so every close path returns it to the opener; the opener comes from the Header click (`onMenu(e.currentTarget)`, held in an `AppLayout` ref); a `matchMedia("(min-width: 1024px)")` change closes the drawer. Close button uses `transition-colors` because `transition-all` animates the inherited visibility and blocks `focus()`.
