- Escape: the mobile nav drawer (only custom overlay) closes on Escape and returns focus to the menu button (after fix A). Month pickers and selects are native controls.

- Month input: ArrowUp/Down changes the month and updates `?month=`.

## Changed
- `frontend/src/shared/components/layout/Sidebar.tsx` — **fix A**: the closed mobile drawer was translated off-screen but its 5 controls stayed in the Tab order (invisible focus). Closed drawer is now `invisible` below `lg`; opening moves focus to the close button; Escape closes and restores focus. Close button uses `transition-colors` because `transition-all` animates the inherited visibility and blocks `focus()`.
- `frontend/src/shared/components/layout/AppLayout.tsx` — stable `closeMenu` callback so the drawer effect does not re-run on every render.
- `frontend/src/shared/components/layout/Header.tsx`, `frontend/src/features/chat/AdminChatPage.tsx`, `frontend/src/features/support-report/SupportReportForm.tsx` — **fix B**: menu/language/theme buttons (32–36px), chat client select (32px), chat suggestion buttons (32px), support file/client/month inputs (36px) raised to the 44px design-system target.
- `frontend/src/features/reports-archive/ReportsPage.tsx` — **fix C**: archive month links were 18px tall; now 44px.
- `frontend/src/shared/utils/report-requests.ts`, `frontend/src/shared/i18n.tsx`, `frontend/src/features/support-report/SupportReportForm.tsx` — **fix D**: `supportErrorText` leads 4xx upload errors with `support.invalid` (mn/en); server text unchanged. Test in `frontend/tests/shared/utils/report-requests.test.ts`.
