# 3.4 `POST /api/chat`

Date: 2026-11-06 · Agent: claude · Commit: the commit that adds this file (`git log -- <this file>`)

## Asked
Roadmap 3.4: embed the question, top-k by cosine with an optional client filter, grounded answer with sources; tested with fakes.

## Changed
- `src/docs-chat/chat.ts` — `answerQuestion` (top 8, zero chunks → localized "don't know" with no model call, empty model text → same), `buildPrompt` (numbered excerpts `[n] path › heading`, answer only from them, exact don't-know sentence, locale language, cite by number, excerpts are data), `DONT_KNOW` mn/en.
- `src/backend/db.ts` — `searchDocChunks` (raw SQL `ORDER BY embedding <=> $v::vector LIMIT k`, optional `client =`), `docClients`.
- `src/backend/server.ts` — `POST /api/chat` (`express.json` 16 kB; question trimmed 1-1000, locale `mn|en`, client optional non-empty string, else 400) → `{answer, sources:[{path, heading}]}`; `GET /api/chat/clients`. Chat deps are `createApp`'s third parameter with real defaults. Logs `chat: 200 in Nms, K sources` / `chat: failed in Nms`; other errors stay `500 Internal error`.
- `tests/backend/server.test.ts` — 5 tests: validation 400 + trimming, zero rows skip the model (both locales), prompt numbering + sources shape + client/limit passed, clients list, log privacy on success and provider failure.
