# 3.3 Vertex adapter and `npm run docs:index`

Date: 2026-11-06 · Agent: claude · Commit: the commit that adds this file (`git log -- <this file>`)

## Asked
Roadmap 3.3: bounded Vertex embed + generate adapter, and an explicit indexing command that skips unchanged chunks.

## Changed
- `package.json` — `@google/genai` promoted to a direct dependency at the locked `1.52.0`; script `docs:index`.
- `src/docs-chat/vertex.ts` — `embed(texts, 'document'|'query')` (`gemini-embedding-001`, 768 dims, `RETRIEVAL_DOCUMENT`/`RETRIEVAL_QUERY`, batches of 16, sequential) and `answer(prompt)` (`gemini-2.5-flash`, temperature 0, 1024 output tokens, thinking off). `GOOGLE_CLOUD_PROJECT` required, `GOOGLE_CLOUD_LOCATION` default `us-central1`, ADC. 30 s timeout per call, 3 attempts (SDK retries 408/429/5xx). Shape check on the returned vectors.
- `src/backend/db.ts` — `docChunkHashes`, `insertDocChunk` (raw SQL, `::vector`, `ON CONFLICT DO NOTHING`), `deleteDocChunksExcept`.
- `scripts/index-docs.ts` — walk `documents/**/*.md`, chunk, embed only unknown hashes batch by batch (an interrupted run keeps its progress), delete rows whose hash is gone, print counts only. Refuses an empty corpus rather than deleting the whole index. Embedded text is `heading + content` so split chunks keep their section context.
- `AGENTS.md` — `src/docs-chat/` is a framework-free feature folder; `@google/genai` only in `vertex.ts`.
- `for-agents/commands.md`, `for-agents/env.md` — the command and its variables.
