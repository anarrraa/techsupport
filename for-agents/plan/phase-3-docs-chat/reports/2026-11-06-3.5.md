- `frontend/src/types/dashboard.ts` — optional `sources` on `ChatMessage`.
- `frontend/src/shared/i18n.tsx` — notice/placeholder/suggestions now describe documentation questions (the old ones asked about tickets, which the chat must not answer); `chat.client`, `chat.allClients` in mn + en.
- `README.md` — dev commands mention `POST /api/chat` and `npm run docs:index`.
- `frontend/tests/shared/utils/report-requests.test.ts` — request shape (method, JSON body with/without client, timeout signal, clients URL) and no echo of a 500 body.
