# 3.2 Markdown chunker

Date: 2026-11-06 · Agent: claude · Commit: the commit that adds this file (`git log -- <this file>`)

## Asked
Roadmap 3.2: pure chunker `src/docs-chat/chunk.ts`, TDD, synthetic fixtures only.

## Changed
- `src/docs-chat/chunk.ts` — `chunkDocument({path, text})`: splits on ATX headings (ignores fenced code and `#RRGGBB…` lines with no space), heading = `H1 › H2 › H3` without emphasis marks, caps chunks at 1500 chars preferring a line/word break with 150-char overlap, drops heading-only/whitespace sections, de-duplicates identical chunks in one file. `contentHash` = sha256(path, heading, content), so the same boilerplate in two files is two rows (the column is unique). Path rule: exactly `documents/<client>/<system>/<file>.md`, anything else throws with that pattern in the message.
- `tests/docs-chat/chunk.test.ts` — 8 tests, synthetic markdown only.

## Verified
- `npm test` → 180 tests, 179 pass / 0 fail / 1 skipped (was 172/171/1)
- `npm run typecheck` → exit 0
- `npm run build` → exit 0
- Real corpus dry pass (counts only): 279 files → 2762 chunks, max 1500 chars, avg 958; no path rejected (all files are exactly client/system depth).
