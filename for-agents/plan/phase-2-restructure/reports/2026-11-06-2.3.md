# 2.3 Share report payload types with the frontend

Date: 2026-11-06 · Agent: claude · Commit: see `git log` "Share report payload types with the frontend"

## Asked
Roadmap 2.3: where a frontend type copies a backend API payload type, replace it
with `import type` from the backend's pure file; keep frontend-only view types;
report mismatches instead of reshaping backend types.

## Changed
- `frontend/src/features/monthly-report/monthly-metrics.ts` — deleted the copied
  `MonthlyMetrics` + `BreachCounts`; `import type { MonthlyMetrics }` from
  `src/monthly-report/monthly-report.ts`. Field-for-field identical before.
- `frontend/src/types/report.ts` — `MonthlyReport.coverage` inline shape replaced by
  `import type { CaptureCoverage }` from the same file (server passes `report.coverage` through).
- `frontend/src/shared/utils/report-requests.ts` — deleted `SupportPeriod`
  (`{ from; to }`); uses `import type { Period }` from `src/support-report/support-report.ts`
  (`/api/support-reports/period` returns `suggestPeriod()` → `Period`).
- `frontend/tsconfig.json` — `allowImportingTsExtensions: true` (valid with its
  `noEmit: true`). Needed because the frontend's `tsc` now typechecks the backend
  files and their `.ts`-suffixed imports (`monthly-report.ts` → `shared/jira.ts` →
  `shared/config.ts`, `shared/http.ts`, `reminder/delivery-windows.ts`).
- Framework check: `support-report.ts` has no imports; `monthly-report.ts` reaches
  only `shared/jira.ts`, `shared/config.ts`, `shared/http.ts`, `reminder/delivery-windows.ts`
  — no express/pdfkit/exceljs/Prisma/Flue.

## Kept (frontend-only or no backend type exists)
- `MonthlyReport`, `Metric`, `PriorityBreakdown`, `TrendPoint`, `Priority`
  (`types/report.ts`, `types/metrics.ts`): the dashboard shape. The server builds that
  body inline in `src/backend/server.ts` (express file), so there is no pure backend
  type to import.
- `ChatMessage`, `TeamMember` (`types/dashboard.ts`): no backend counterpart.
- `SupportConfig` (`report-requests.ts`): server builds `{ id, client, groups }` inline in `server.ts`.

## Mismatches found (reported, not changed)
- The deleted frontend `MonthlyMetrics` was commented "`GET /api/reports/:month` body".
  It is not: the server already maps `MonthlyMetrics` to the dashboard shape
  (`summary`, `byPriority` rows, `team`, `trend`) and adds `priorityTotals`.
  `toMonthlyReport` repeats that mapping client-side and is used only by its test.
  Candidate for deletion or for moving the mapping into a pure backend file; not done (behavior/scope).
- Server sends `summary.avgFirstResponseMinutes: { value: null, previous: null }`;
  frontend types it `Metric | null`. Compatible, not identical. `priorityTotals` is
  sent but not in the frontend type (unused).
