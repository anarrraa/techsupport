## Changed
- `src/shared/` — config, http, jira, teams-bot, teams-webhook (from `src/lib/`).
- `src/reminder/` — sla, reminder-message, reminder-intro, delivery-windows, run-journal.
- `src/escalation/` — escalation, escalation-config, escalation-state, direct-messages, ticket-digest.
- `src/monthly-report/` — `monthly-report.ts` (from `src/lib/queries/`), `export.ts` (from `src/backend/`).
- `src/support-report/` — `support-report.ts`, `input.ts` (was `backend/support-report-input.ts`), `pdf.ts` (was `backend/support-report-pdf.ts`).
- `src/backend/db.ts` — **kept** in `src/backend/`: besides the monthly-report
  snapshot reads/writes, `server.ts` uses `db()` for the generic `/api/health`
  database check, and it owns the one Prisma client the next DB feature (docs
  chat `DocChunk`) will share. Moving it into `monthly-report/` would make another
  feature import monthly-report for its DB handle.
- `src/lib/` removed (empty). `tests/` mirrors: `tests/{shared,reminder,escalation,monthly-report,support-report}/`;
  `tests/backend/` keeps `db.test.ts` and `server.test.ts`.
- `package.json` `test` script globs the new test folders.
- Imports fixed in `src/`, `tests/`, `scripts/trace-run.ts`, `scripts/verify-teams-bot.ts`,
  `scripts/resolve-entra-ids.mjs` (rewritten by resolving each relative specifier
  against the old location; diff contains only import-line and comment changes).
  `flue.config.ts` has no imports of moved files.
- `pdf.ts` font URL `../../assets/fonts/...` unchanged: same directory depth.
- `AGENTS.md` — `src/lib/` framework rule replaced by the feature-folder rule with
  named adapters (pdfkit: `monthly-report/export.ts`, `support-report/pdf.ts`;
  exceljs: `monthly-report/export.ts`, `support-report/input.ts`; Prisma: `backend/db.ts`;
  express: `backend/server.ts`; `@flue/runtime`: `agents/`, `workflows/`). Checked by grep.
- Path mentions updated in `README.md`, `.env.example`, `for-agents/` (architecture, data,
  gotchas, conventions, commands, env, roadmap, TODO, claude-notes, PRDs/BRD), code
  comments, and `frontend/src/utils/monthly-metrics.ts` comment. Cited line numbers
  stay valid (moved files keep their line counts).
